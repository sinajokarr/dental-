# JOKAR DENTAL — PROJECT BRIEF

> نسخه: 1.0 · تاریخ: 2026-11-11 · وضعیت: **در انتظار تأیید کارفرما**

## ۱. هدف

طراحی و توسعه یک وب‌سایت دندانپزشکی **فوق‌لوکس، آینده‌نگر و چهارزبانه** برای JOKAR DENTAL.

تمرکز فاز فعلی:

- کیفیت طراحی UI و UX
- انیمیشن‌های سینمایی
- مدل سه‌بعدی تعاملی دندان
- Glassmorphism کنترل‌شده
- سرعت بالا و عملکرد روان در موبایل

Google Ads، مارکتینگ و Tracking تبلیغاتی **خارج از محدوده فاز فعلی** هستند. با این حال معماری سایت طوری طراحی می‌شود که بعداً بدون بازنویسی بتوان آن‌ها را اضافه کرد.

اولویت تصمیم‌ها: **Trust → Clarity → Consultation → Visual Excellence → Performance**

## ۴. خدمات بیماران بین‌المللی (تأییدشده)

- هماهنگی هتل و اقامت
- ترانسفر فرودگاهی
- مترجم برای بیماران خارجی
- پکیج‌های درمانی دندانپزشکی
- هماهنگی کامل امور بیماران بین‌المللی
- مشاوره به زبان بیمار (فارسی، انگلیسی، آلمانی، ترکی)
- ارزیابی آنلاین با عکس یا رادیوگرافی قبل از سفر (از طریق WhatsApp)
- اقامت معمول ۳ تا ۸ روز، بسته به درمان
- پیگیری پس از درمان؛ ضمانت با شرایط وابسته به نوع درمان

## ۸. تصاویر

تصاویر از منابع دارای مجوز تجاری تهیه می‌شوند (Unsplash و Pexels، یا در صورت نیاز Adobe Stock با خرید License). مجوز هر تصویر در `docs/ASSET_LICENSES.md` ثبت می‌شود.

قوانین استفاده از تصاویر stock:

- تصاویر stock فقط **حالت تزئینی و فضاسازی** دارند.
- هرگز به‌عنوان کلینیک واقعی، پزشکان Jokar Dental یا نتیجه قبل و بعد درمان معرفی نمی‌شوند.
- بخش‌های «قبل/بعد» و «پزشکان» تا رسیدن تصاویر واقعی نمایش داده نمی‌شوند.
